## Q1. isa 是什么？

Runtime 题核心是“动态性成本与边界”。消息发送由 `objc_msgSend` 基于 `isa` 查找缓存与方法列表；找不到进入动态解析与消息转发链。资深实践中 swizzling 仅用于可控、可回滚场景（埋点、防护、兼容），必须保证幂等、线程安全、和调用原实现；另外要评估调试可观测性与后续维护成本。

**面试加分回答框架：**
1. 先给结论与适用边界。
2. 说明底层机制或关键原理。
3. 给出真实项目中的坑与治理方案。
4. 补充如何验证（指标 / 工具 / 回归方式）。

### 代码示例

```objective-c
Method oldMethod = class_getInstanceMethod([UIViewController class], @selector(viewDidAppear:));
Method newMethod = class_getInstanceMethod([UIViewController class], @selector(ss_viewDidAppear:));
method_exchangeImplementations(oldMethod, newMethod);
```
