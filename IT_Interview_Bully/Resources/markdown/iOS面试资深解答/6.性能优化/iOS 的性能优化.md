## Q1. iOS 开发全方位性能优化完整指南

性能优化要指标先行：启动（TTID/TTFD）、渲染（FPS/卡顿率）、内存峰值、耗电、网络时延。方法上分层治理：启动阶段减少 dyld/ObjC 初始化负担；渲染阶段避免主线程重活与不必要离屏；内存阶段控制大对象生命周期与图片解码策略。资深实践强调“可观测 + 基线 + 回归门禁”，避免一次性优化后回退。

**面试加分回答框架：**
1. 先给结论与适用边界。
2. 说明底层机制或关键原理。
3. 给出真实项目中的坑与治理方案。
4. 补充如何验证（指标 / 工具 / 回归方式）。

### 代码示例

```swift
final class SSImageDecoder {
    private let queue = DispatchQueue(label: "com.ss.decode", qos: .userInitiated)

    func decode(_ data: Data, completion: @escaping (UIImage?) -> Void) {
        queue.async {
            let image = UIImage(data: data)
            DispatchQueue.main.async { completion(image) }
        }
    }
}
```
