## Q1. 3.7 weak ，unreatin 修饰的 self

属性语义要和生命周期一致：`strong` 用于拥有关系，`weak` 用于避免环（典型是 delegate/IBOutlet），`assign` 仅用于标量或不拥有对象。面试里常见加分点是：`weak` 置零是 runtime 维护的 side table 行为；`unsafe_unretained` 性能略高但有野指针风险，一般只在性能敏感且可证明安全的场景使用。
