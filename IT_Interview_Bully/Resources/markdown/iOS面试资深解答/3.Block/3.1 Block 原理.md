## Q1. 3.1 Block 原理

这类问题建议按“原理 -> 典型坑 -> 工程实践 -> 监控验证”四段回答。资深候选人要给出可落地策略：明确边界、可测试、可观测、可回滚，而不是只停留在 API 记忆层。

**面试加分回答框架：**
1. 先给结论与适用边界。
2. 说明底层机制或关键原理。
3. 给出真实项目中的坑与治理方案。
4. 补充如何验证（指标 / 工具 / 回归方式）。
