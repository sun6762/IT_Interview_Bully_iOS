## Q1. 什么是函数式编程？

Swift 相关题建议从“语言机制如何影响架构”回答：值语义提升并发安全，协议与泛型提升抽象复用，派发机制影响性能与可替换性。Combine/Rx 重点在背压、线程调度和生命周期管理；业务层要保证订阅释放、错误收敛和可测试性（可注入 scheduler / mock publisher）。

## Q2. 闭包？

Block/闭包题加分点在内存布局与捕获语义：全局块在数据区，栈块需拷贝到堆后长期持有；捕获值类型是拷贝，捕获引用类型是引用计数管理。`__block` 改变的是变量存储与可变性，不自动解决循环引用。资深代码会统一 `[weak self]` + guard 语义，明确强持有窗口，并在异步链路中设置取消策略。

**面试加分回答框架：**
1. 先给结论与适用边界。
2. 说明底层机制或关键原理。
3. 给出真实项目中的坑与治理方案。
4. 补充如何验证（指标 / 工具 / 回归方式）。

### 代码示例

```swift
final class SSProfileViewController: UIViewController {
    private var onFinish: (() -> Void)?

    func bind() {
        onFinish = { [weak self] in
            guard let self else { return }
            self.dismiss(animated: true)
        }
    }
}
```
