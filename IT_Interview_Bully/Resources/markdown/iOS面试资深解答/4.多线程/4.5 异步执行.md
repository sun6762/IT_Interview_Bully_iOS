## Q1. 4.5 异步执行

并发设计优先从数据一致性出发，而不是 API 选择。串行队列适合状态机与资源互斥；并行队列适合可并行任务；同步/异步关键在调用方等待语义。现代 Swift 中建议以 structured concurrency（TaskGroup/async-await/actor）建模，减少 callback 地狱。资深面试答案应补充取消传播、优先级反转、和主线程回切策略。

**面试加分回答框架：**
1. 先给结论与适用边界。
2. 说明底层机制或关键原理。
3. 给出真实项目中的坑与治理方案。
4. 补充如何验证（指标 / 工具 / 回归方式）。
### 代码示例

```swift
actor SSQuestionStore {
    private var cache: [String: String] = [:]

    func save(id: String, content: String) {
        cache[id] = content
    }

    func read(id: String) -> String? {
        cache[id]
    }
}
```
