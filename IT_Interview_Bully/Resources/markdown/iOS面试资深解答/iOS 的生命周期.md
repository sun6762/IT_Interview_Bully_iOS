## Q1. iOS 的生命周期

设计模式题关键是边界与演进。单例应限制在无状态基础设施（日志、配置中心）并可替换注入；业务对象避免全局单例。MVC/MVVM 选择看团队与测试策略，MVVM 在状态驱动和 UI 测试可观测性更有优势。生命周期题要强调场景切换、后台任务、内存告警与恢复流程的一致性。

**面试加分回答框架：**
1. 先给结论与适用边界。
2. 说明底层机制或关键原理。
3. 给出真实项目中的坑与治理方案。
4. 补充如何验证（指标 / 工具 / 回归方式）。
